# TéléCast MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build TéléCast, an iOS app (sideloaded, no Mac) that detects videos in an in-app browser and casts them to DLNA TVs reliably (auto strategy fallback, phone relay, auto-resume, ad/popup blocking).

**Architecture:** SwiftUI app (`TeleCast/`) on top of a local Swift package `CastKit` split into `CastCore` (pure, unit-tested logic: parsing, planning, session state machine) and `CastNet` (Apple networking: relay HTTP server on Network.framework, URLSession upstream, BSD-socket SSDP sweep, CommonCrypto). Video detection is a JavaScript file injected in every frame, tested on Windows with Playwright WebKit. The Xcode project is generated by XcodeGen; GitHub Actions (macOS) runs tests and produces an unsigned `.ipa`.

**Tech Stack:** Swift 5 language mode, iOS 17+, SwiftUI + Observation, WebKit, Network.framework, AVFoundation, MediaPlayer, CommonCrypto, XcodeGen, GitHub Actions, Node 24 + Playwright (WebKit) for JS tests, ffmpeg for test media, Python for the fake DLNA renderer.

**Spec:** `docs/superpowers/specs/2026-10-05-telecast-design.md`

Classifier rules: http(s) only; `AdHostMatcher.builtIn` host → ignored("ad"); `googlevideo.com`/`youtube.com` → ignored("youtube"); `.m3u8` anywhere in URL or HLS mime → hls; `.mpd` or `application/dash+xml` → dash; segment-like (`.ts .m4s .aac .vtt .key`, mime `video/mp2t`, `video/iso.segment`) → ignored("segment"); `mp4 m4v mov webm mkv` or `video/*` → progressive, except `looksLikeSegment` when `via` is `fetch|xhr|perf` → ignored("segment"); else ignored("not-media").

Score: playing +50; hls +10 (+10 if `hls.isMaster`); media element via (`video-src|source|media-event`) +15; duration ≥ 60 → +min(d/60, 30), < 60 → −40; DRM −100; dash −20.

Tests:
- classify `https://c.net/a/master.m3u8?t=1` → `.media(.hls)`; `https://c.net/get?id=1` mime `application/vnd.apple.mpegurl` → hls; `https://c.net/v.mpd` → dash; `https://c.net/seg-12.ts` → ignored; `https://c.net/movie.mp4` via `video-src` → progressive; `https://c.net/seg-3.mp4` via `fetch` → ignored; `https://rr3.googlevideo.com/videoplayback` → ignored.
- ingest twice same path with different query → 1 candidate, URL updated to latest.
- `playing` message for frame F marks the most recent hls candidate of frame F as playing and sets duration.
- A playing 1 h hls candidate outranks a 20 s mp4 pre-roll.
- `reset()` empties.

Commit: `feat(core): media detection model and classifier`
